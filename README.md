# Pokémon Finder Web Application

## Project Description
This is a responsive web application that fetches and displays dynamic Pokémon data from the public PokéAPI.  
Users can search for any Pokémon by name or ID and view detailed information in a modern card layout.

---

## Technologies Used
- HTML5
- Vanilla JavaScript (ES6+)
- Tailwind CSS (CDN)
- PokéAPI (https://pokeapi.co/)

---

## Features
- Fetch API with async/await
- Full error handling (404 + network errors)
- Loading spinner animation
- Disabled button during request
- Dynamic rendering of Pokémon types
- Multiple Pokémon sprites
- Dark mode toggle
- Fully responsive design
- Animated card appearance

---

## How to Run Locally
1. Download or clone the repository
2. Open the folder
3. Double-click `index.html`
4. Start searching Pokémon!

No installation required.
